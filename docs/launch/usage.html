    One count per device per day, kept on the device itself; nothing here identifies anyone. "New" means the device had never been counted before, so the all-time new count is a ceiling on devices reached (clearing browser storage makes a device new again). "Finished the quiz" is counted once per device per day with no answers attached. "Where devices came from" only knows M2V's own tagged links (for example app.match2vote.org/?from=qr); everything else is untagged. Days and hours are Eastern time; the hourly chart shows when each device's first open of the day happened. Android usage is in Play Console under Statistics. How this is counted: privacy policy.
